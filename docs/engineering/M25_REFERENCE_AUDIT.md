# V1/V2 reference audit

Read-only inspection covered both workspace and integration AGENTS.md files, v1 component instructions, and historical 31/32 Source instructions. No earlier source/environment/Git state/checkpoints were modified or loaded. Source/metadata searches excluded weight/data payloads. No standalone reusable screenshot or training web-dashboard asset was found in the inspected historical roots.

V1 integration references: `src/codexa_workspace/monitoring/{dashboard,reader,render}.py`, `scripts/training_dashboard.py`, monitoring tests, training telemetry alias, and `src/codexa_workspace/review/dashboard.html`. Canonical telemetry is `LLM-Training/src/llm_training/telemetry.py`; hardware monitoring is in that component. Relevant architecture/inference sources were searched, including inference token/context callbacks. The terminal monitor is implemented with Rich, status documents and incremental JSONL tails. The separate HTML interface is a response-review tool, not training monitoring. Source tests exist; earlier applications/tests were not executed in their protected environments, so their present operational state was not independently certified.

Adapted concepts: read-only process separation, slate/blue palette, restrained panels, status hierarchy, null unavailable values, durable event records, resume-attempt boundaries and incremental tails. New v3 code is independently integrated, not an import of the older training implementation. Rejected: Kitty/systemd viewer coupling, supervisor/notification controls, fixed resource thresholds, full-history scans on every update and reviewer-specific UI.

V2 canonical `src/llm_numpy/training/{progress,trainer,metrics}.py` implements terminal progress, CSV metrics and token budgets. Searches of canonical source, scripts, docs and asset metadata found no training web dashboard. Adapted the simple explicit budget concept only. Rejected zero-filled absent values and numerical-engine coupling. No v2 source was copied; an explicit code license was not found in the inspected checkout.

V1 carries MIT licensing; palette/layout inspiration is acknowledged in THIRD_PARTY_NOTICES.md. uPlot is pinned and bundled with its MIT license. No private logs or historical assets were copied into public documentation.
